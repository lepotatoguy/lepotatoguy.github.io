HemeLB Scripts

Helper Python scripts used in the HemeLB guides.

  • create_geometry_pyvista.py: Builds a test cylinder geometry (along the Z-axis) with PyVista.
  • create_geometry_trimesh.py: Builds the same test cylinder geometry with trimesh.
  • process_outputcsv.py: Reads an extracted HemeLB output CSV and plots the results (pandas, matplotlib).
  • unit_conversion.py: Lattice-Boltzmann unit conversion between physical and lattice units.

Browse all scripts on GitHub.
